# 🚢 Titanic Data Analysis

An Exploratory Data Analysis (EDA) project on the Titanic dataset using Python and popular data analysis libraries. This project explores passenger survival patterns based on gender, passenger class, and age.

## 📌 Project Overview

The goal of this project is to analyze Titanic passenger data and identify patterns associated with survival.

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Kaggle Notebook

## 📊 Key Insights

- **Gender:** Female passengers had a survival rate of 74.20%, compared with 18.89% for male passengers.
- **Passenger Class:** First-class passengers had a survival rate of 62.96%, compared with 24.24% for third-class passengers.
- **Age Group:** Children had a survival rate of 57.97%, compared with 22.73% for senior passengers.

## 🔍 Analysis Performed

- Data exploration and inspection
- Survival rate analysis
- Comparison by gender and passenger class
- Age-group survival analysis
- Data visualization
